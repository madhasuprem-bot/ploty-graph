# Sample Dataset Visualizer

## Topic
Plot sample datasets such as monthly sales and student marks using Chart.js.

## Technologies
- HTML5
- CSS3
- JavaScript
- Chart.js

## Files
- index.html - Main webpage
- style.css - Website styling
- script.js - Dataset and chart functionality

## How to Run
1. Extract the ZIP file.
2. Open the `index.html` file in Google Chrome, Edge, or Firefox.
3. Click the dataset buttons to change the chart.
4. Internet connection is required because Chart.js is loaded from its CDN.

## Features
- Monthly Sales line chart
- Student Marks bar chart
- Attendance bar chart
- Responsive design
- Interactive Chart.js tooltips
- Dataset switching without reloading the page
